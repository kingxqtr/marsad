# المقارنات بين السفن

## خطوات العمل

1. نفّذ لكل سفينة الخطوات 1 إلى 4 من سير العمل (fetch ← draft ← بحث ← صور) واحصل على ملف مكتمل لكل سفينة.
2. اجمعها في ملف واحد:
```json
{
  "meta": { "...": "نفس meta لكل السفن: نفس الإصدار ونفس تاريخ التحقق" },
  "ships": [ { "...": "السفينة الأولى" }, { "...": "السفينة الثانية" } ],
  "comparison": {
    "winners": [ { "use": "القتال", "winner": "Perseus", "why": "سطر واحد بالسبب" } ],
    "fairness": "نفس الإصدار ونفس الوحدات والتجهيز الأصلي لكل السفن.",
    "notes": [ "..." ]
  }
}
```
3. ابنِ وانشر كالتقرير العادي. القالب يتحول تلقائيًا إلى وضع المقارنة عند وجود سفينتين أو أكثر.

## ما يعرضه القالب في وضع المقارنة

- بطاقات السفن بصورها، والفائز في كل استخدام، ورادار التقييم الوظيفي متراكبًا (أسماء محاور `uses.ratings` يجب أن تكون متطابقة بين السفن).
- وجهًا لوجه: ضرر الطيار، ضرر الطيار والطاقم، Hull، Shield، مدى الكوانتم، SCM، السرعة القصوى، الحمولة، الحد الأدنى للطاقم، السعر بالدولار، سعر aUEC — مع نجمة للأفضل.
- الأحجام بالمقياس، وجدول متقابل يشمل الريال القطري والصواريخ وحالة الذخيرة عند الاستلام.
- تقرير كامل بالأقسام الأحد عشر لكل سفينة في تبويب، بما فيها الحاسبات ودليل التعبئة الخاص بها.

## قواعد العدالة

- نفس إصدار اللعبة ونفس الوحدات ونفس الافتراضات لجميع السفن.
- نفس تعريف الحقول: `crew.min` الرسمي لكل السفن، و`total` = الطيار + الطاقم دون PDC لكل السفن.
- التجهيزات الأصلية Stock أولًا؛ المعدلة في ملاحظات منفصلة.
- لا تقارن مواصفات Concept بأداء LIVE كأنهما متاحان؛ وسم كل رقم Concept.
- دليل التعبئة يُكتب لكل سفينة على حدة؛ لا تنسخ دليل سفينة لأخرى إلا للخطوات المتطابقة والمؤكدة.

## جدول الفائز في كل استخدام

استخدامات مقترحة: القتال، ضرر الطيار، إجمالي الضرر، الدفاع، الشحن، الاستكشاف، اللعب الفردي، اللعب مع طاقم، تكاليف التشغيل، القيمة مقابل السعر. سبب من سطر واحد لكل بند. لا تختزل المقارنة في DPS أو HP. إن لم تكفِ البيانات فاكتب الفائز «غير محسوم» مع ما ينقص.

## إبداع في المقارنة عند الطلب

إن طلب المستخدم مقارنة إبداعية إضافية، أضفها في `comparison.notes` أو كأقسام نصية، مثل: كم رحلة كمية بين ArcCorp وmicroTech بخزان واحد لكل سفينة (من `range_gm` والمسافة 59 Gm)، أو كم رشقة توربيدات تحتاجها كل سفينة لإسقاط شيلد الأخرى نظريًا (مع وسم «تقدير نظري» وشرح افتراضاته).
