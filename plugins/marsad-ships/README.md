# مرصد السفن — Marsad Ships

إضافة (Plugin) لـClaude تعدّ تقريرًا عربيًا تفاعليًا شاملًا عن أي سفينة في Star Citizen بمجرد ذكر اسمها، وتنشره صفحة Artifact بهوية «المرصد».

مثال حي: تقرير Polaris المنشور مع الإصدار 2.0.0.

## ماذا تفعل

- تجلب الأرقام من بيانات اللعبة الحالية (Star Citizen Wiki API)، ومن RSI Ship Matrix الرسمي، ومن UEX لأسعار aUEC والوقود والمسافات.
- تكتب التقرير بالعربية من اليمين لليسار، مع بقاء أسماء اللعبة والمصطلحات بالإنجليزية.
- تغطي 11 قسمًا + الخلاصة: الاستخدامات، التعريف، الأسلحة بالتفصيل، الضرر DPS (الطيار وحده / الطاقم / الإجمالي)، التحمل، الوقود والحركة، المكونات، الحمولة والمرافق، الأسعار، آراء اللاعبين، ودليل ما بعد الشراء (هل تأتي معبأة؟ كيف تعيد التعبئة؟ من أين تشتري الصواريخ والتوربيدات؟).
- حاسبة الوقود الكمي: اختر المحرك ومستوى الخزان ورحلة جاهزة بين الكواكب أو مسافة يدوية، فتعرف الوقود المطلوب والمدى والزمن والتكلفة.
- حاسبة السعر: خيارات متجر RSI أو سعر مخصص، بالضريبة وبدونها، بالدولار والريال القطري، مع رسوم البنك.
- اختيار المحطات المأهولة لحساب الضرر، ومحاكاة إطلاق الرشقات، وحاسبة تكلفة تعويض الصواريخ والتوربيدات.
- مقارنة إبداعية بين سفينتين أو أكثر: الفائز في كل استخدام، رادار متراكب، وجهًا لوجه، الأحجام بالمقياس، وتقرير كامل لكل سفينة.

## التثبيت

### Claude Code (الويب أو الطرفية)
```
/plugin marketplace add kingxqtr/marsad
/plugin install marsad-ships@marsad
```
أو بأمر واحد في الإصدارات الحديثة:
```
/plugin install marsad-ships --marketplace kingxqtr/marsad
```

### Claude Cowork
افتح الملف `dist/marsad-ships.plugin` في محادثة Cowork واضغط زر التثبيت الذي يظهر في المعاينة.

### claude.ai (مهارة فقط)
ارفع `dist/star-citizen-ship-encyclopedia.zip` من إعدادات المهارات (Skills) في حسابك، في المكان نفسه الذي رفعت منه المهارة القديمة.

> مهم: إذا ثبّت الإضافة فاحذف المهارة القديمة `star-citizen-ship-encyclopedia` (الإصدار 1.2.0) من حسابك أو استبدلها بالـZIP الجديد، حتى لا تعمل نسختان معًا.

## الاستخدام

- اكتب اسم السفينة فقط: `Polaris` أو `بولارس` أو `تقرير عن Carrack`.
- أو استخدم الأوامر:
  - `/marsad-ships:ship Polaris`
  - `/marsad-ships:compare Polaris Perseus`
- لسؤال محدد اكتب السؤال مباشرة: «كم DPS الطيار وحده في Perseus؟» فتأتيك إجابة نصية دون صفحة.
- لتحديث تقرير قديم: «حدّث تقرير Polaris» فيُعاد النشر على الرابط نفسه.

## البنية

```
marsad-ships/
├── .claude-plugin/plugin.json, icon.png
├── commands/ship.md, compare.md
└── skills/star-citizen-ship-encyclopedia/
    ├── SKILL.md                 سير العمل والقواعد
    ├── scripts/                 fetch_ship.py · draft_report.py · build_report.py
    ├── assets/                  report-template.html (الهوية والحاسبات) · example-report.json
    └── references/              المراجع التفصيلية لكل قسم
```

السكربتات تعمل بمكتبة Python القياسية فقط (Pillow اختياري لضغط الصور).

## تعديل الهوية

الألوان والخطوط والحركة في متغيرات `:root` داخل `assets/report-template.html`؛ أي تعديل هناك ينطبق على كل التقارير القادمة. التفاصيل في `references/identity.md`.
